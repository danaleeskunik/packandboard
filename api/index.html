לשותפים

מדריך טיול דיגיטלי אישי, ישר מהמערכת שלכם

שולחים לנו את פרטי הטיול. מקבלים בחזרה קישור למדריך אישי שנפתח בטלפון, בלי הורדה מהחנות, ואפשר להוסיף אותו למסך הבית.

  1. 1. שולחים את הטיולבקשה אחת עם פרטי הטיול: ימים, טיסות, הזמנות ומיתוג שלכם.
  2. 2. מקבלים קישורהקישור מוכן בתוך שניות, או ממתין לאישור שלנו אם סוכנות חדשה.
  3. 3. שולחים למטיילהוא פותח, והמדריך נשמר גם לשימוש בלי אינטרנט אחרי פתיחה ראשונה.

נסו עכשיו

הדביקו את מפתח ה-API שקיבלתם. הטיול שמופיע למטה הוא דוגמה: אפשר לשנות בו כל דבר ולשלוח. המפתח נשלח ישירות לשרת שלנו ולא נשמר בדפדפן.

מה שנשלח בבדיקה הוא טיול אמיתי תחת המפתח שלכם, והוא נספר במכסה החודשית. את הטיול אפשר למחוק בקריאה אחת (ראו למטה).

שלוש הקריאות החשובות

כתובת בסיס: https://pab-api.dana-lees.workers.dev. בכל קריאה: Authorization: Bearer pab_...

יצירת טיול

curl -X POST https://pab-api.dana-lees.workers.dev/v1/trips \
  -H "Authorization: Bearer $PAB_KEY" \
  -H "Content-Type: application/json" \
  -d @trip.json

התשובה (201):

{ "trip_id": "k3j9x0ab", "status": "published",
  "link": "https://packandboard.com/t/#k3j9x0ab.<key>",
  "warnings": [], "review_reason": null }

את link שולחים למטייל כמו שהוא, כולל כל מה שאחרי #.

עדכון טיול

curl -X PATCH https://pab-api.dana-lees.workers.dev/v1/trips/k3j9x0ab \
  -H "Authorization: Bearer $PAB_KEY" -H "Content-Type: application/json" \
  -d '{"patch": {"title": "שם חדש"}}'

הקישור נשאר זהה. המטייל רואה את העדכון בפתיחה הבאה (או ברענון).

מחיקה

curl -X DELETE https://pab-api.dana-lees.workers.dev/v1/trips/k3j9x0ab -H "Authorization: Bearer $PAB_KEY"

סטטוסים

סטטוסמשמעות
publishedהקישור פעיל.
needs_reviewממתין לאישור (החשבון מוגדר לאישור, או שהבדיקות מצאו משהו חריג, למשל יום מחוץ לתאריכי הטיול). warnings מסבירים. הקישור לא מציג כלום עד לאישור.
422הטיול נדחה. details אומר מה לתקן, ושולחים שוב.

מבנה הטיול

חובה: title, dates.start ו-dates.end (בפורמט YYYY-MM-DD, עד 60 יום), ו-days עם date ו-title לכל יום. כל השאר אופציונלי.

שדהמה
days[].rowsשורות הפעילות של היום: label (בוקר, ערב...) ו-text.
days[].tip, days[].placesטיפ ליום, ומקומות (נפתחים במפה).
flightsdir (out או back), number, from, to, dep, arr (תאריך ושעה עם אזור זמן).
bookings, packing, tips, emergencyהזמנות, רשימת אריזה, טיפים כלליים ומספרי חירום.
currencyקוד מטבע בן 3 אותיות, למשל EUR.
brandname, logo_url (https בלבד), colors (#RRGGBB). ערכת הצבעים של המדריך נגזרת מהצבע הראשון. בלי צבע נבחר צבע לפי היעד.
referenceמזהה שלכם (מספר הזמנה). לא מוצג למטייל.

טקסט הוא טקסט רגיל. **כך** מדגיש. HTML מוצג כטקסט ולא מופעל.

לא שולחים מספרי דרכון, כרטיסי אשראי או פרטי תשלום. אין בהם צורך במדריך.

איך מקבלים מפתח

המפתח מונפק על ידינו, והוא מוצג פעם אחת בלבד. בחשבון חדש כל טיול ממתין לאישור שלנו עד שנצבר אמון, ואז עוברים לפרסום מיידי. פנו אלינו: וואטסאפ או office@packandboard.com.

פרטיות

אתם אחראים לנתוני המטיילים שאתם שולחים. Pack & Board מעבדת אותם רק כדי לבנות את המדריך. טיול שנמחק מוסר, והקישור מפסיק לעבוד. הסכם עיבוד מידע זמין לפי בקשה. ראו גם את מדיניות הפרטיות.
